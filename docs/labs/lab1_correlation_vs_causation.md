# Lab1：相關性代表因果關係嗎？（M2，約 50 分鐘）

## 目標
看到「遲到 → 差評」的強烈關聯後，要能做到三件事：
- 提出競爭假設
- 用分層比較檢查混雜因素
- 把結論轉成 T0 可用的特徵

## 步驟
1. **預測（5 分鐘）**：寫下你預期遲到訂單的差評率是準時訂單的幾倍。
2. **觀察（10 分鐘）**：打開 `M2_hypothesis_eda.ipynb` 的 H1，依 `is_late` 分組。
3. **競爭假設（10 分鐘）**：每組提出至少 2 個「同時造成遲到與差評」的因素。
   可以從這幾個方向想：承諾送達天數、買賣雙方距離、偏遠州、品類、賣家品質。
4. **分層檢驗（15 分鐘）**：在混雜因素的每一層內，再比較一次遲到與準時。由你設計分層，執行可以交給 `eda-analyst`。
5. **轉譯（10 分鐘）**：遲到在 T0 無法得知，所以要寫出 2 個 T0 可得的代理特徵（feature card 草稿）。

## 繳交
- 2 張假設卡，內容包含：競爭解釋、分層結果、結論（支持 / 推翻 / 證據不足）
- 2 張代理特徵的 feature card 草稿

## 討論題
- 分層之後關聯仍在，能說「遲到造成差評」嗎？還缺什麼證據？
- 如果公司根據這個結果縮短承諾送達天數，差評一定會下降嗎？（提示：承諾天數變短，遲到機率就會變高。）
