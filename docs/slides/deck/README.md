# 投影片：資料科學心法（74 頁）

## 怎麼看
- **上課播放**：用瀏覽器開 `index.html` → 點任一頁開始。← / → 翻頁，ESC 回總覽，P 列印
- **PDF**：`deck.pdf`（74 頁，1920×1080，文字可搜尋）
- 需要網路：字體（Huninn）與手繪線條（rough.js）從 CDN 載入

## 結構
| 段落 | 檔名前綴 | 頁數 |
|---|---|---|
| 開場：封面、為什麼學、適合對象、先備知識（×3）、自我檢核、工具、課程地圖 | 01–09 | 9 |
| 第 1–6 章：學習目標 → 概念圖解 → 小結＋下一章 | 1xx–6xx | 60 |
| 大總結、結業三問、參考文獻、術語表（×2） | 9xx | 5 |

## 修改與重建
- 每頁一個檔案在 `slides/`；共用樣式 `assets/base.css`、繪圖工具 `assets/draw.js`；設計規則見 `BRIEF.md`
- 截圖檢查：`./shoot.sh <前綴>` → `uv run python contact.py <前綴> 總覽.png`
- 新增或刪除頁面後：`uv run python build.py --pdf`（更新目錄與 PDF）
