人類定邊界，
AI 跑實驗。

AI 讓寫程式、畫圖、跑實驗變得幾乎免費，但它交回來的結果看起來都很合理：程式能跑、分數漂亮，卻可能偷看了未來的資訊，或只是某個月份剛好比較好。這份模板把「判斷什麼可信」做成規則、檔案與自動檢查，讓人類負責問題的邊界與去留，AI 負責執行、記錄，並主動質疑自己的結果。

人類閘門：由你決定 AI 執行 已驗證、可採用

先認識八個名詞

它們都是「讓 AI 守規矩」的手段，由左而右、由弱到強

AI 助手

在終端機裡和你對話、能讀寫檔案與執行程式的 AI（Claude Code、Codex）。

比喻：一位勤快、會寫程式，但會犯「合理錯誤」的助理。

細節收合
  • 兩種都可用；Claude Code 另有 subagent 與 hook
  • 在 repo 根目錄開啟，它會自動讀到 AGENTS.md

AGENTS.md

專案最上層的規則文件，AI 每次開工都先讀。

比喻：新進員工的工作守則。

細節收合
  • 十條鐵律：邊界歸人類、只用預測當下可得的資訊、不讀 holdout、不改原始資料、一次只改一項、每個比較都留紀錄……
  • Claude Code 與 Codex 共用；CLAUDE.md 只是引用它，再補 Claude 專屬設定
  • 擋不住：AI 忘記或誤解規則

Skill 技能

一份標準作業程序：某類工作的步驟與驗收標準。

比喻：一張料理食譜，誰來做都是同樣的品質。

細節收合
  • 共 11 個，放在 .claude/skills/，複本在 .agents/skills/ 給 Codex
  • 用法：「用 data-card 整理資料」
  • 完整清單見 Skill 矩陣

Subagent 子代理

只負責某個角色、有權限限制的 AI 分身。

比喻：會計與稽核分屬不同人，避免球員兼裁判。

細節收合
  • 四個：eda-agent、feature-agent、model-agent、validation-agent
  • validation-agent 只能讀、不能改，任務是試著推翻「模型變好了」
  • Claude Code 專屬；Codex 依 AGENTS.md 角色表自我約束

Hook 掛鉤

AI 做某些動作前後，自動執行的檢查程式。

比喻：門禁系統，刷卡沒過，門就不開。

細節收合
  • guard_paths.py：擋寫入 data/raw/、擋讀取 holdout 資料夾
  • post_edit_tests.py：改了 src/**/*.py 就自動跑洩漏測試；還沒有測試檔也會擋下
  • 另有 .claude/settings.json 的權限規則保護同樣的資料夾

pre-commit

每次 git commit 前自動跑的檢查，Codex 與手動操作也適用。

比喻：出貨前的品管站。

細節收合
  • 三件事：不能提交原始資料、兩份 skill 內容必須一致、src/ 有改動就跑洩漏測試
  • 啟用：pre-commit install

knowledge/

人類與 AI 的共同記憶，只有四份文件。

比喻：研究室的實驗筆記本，換人接手也看得懂。

細節收合
  • brief.md 專案定義（人類核准）
  • data.md 資料說明與坑
  • log.md 研究日誌（AI 每次回報自動追加，失敗也寫）
  • findings.md 人類核可的結論

實驗紀錄

experiments/log.jsonl：每次比較一行，只追加不修改。

比喻：帳本。報告裡每個數字都要對得到一筆帳。

細節收合
  • 必填：run_id、git、輪次、完整特徵清單、模型與參數、每個 fold 的分數
  • 有 fold 分數，才能做同 fold 配對比較

協作模型：三道閘門，一個迴圈

專案切成固定階段，並設下三道人類閘門：走到這裡，AI 必須停下來交給你決定。中間的迭代可以重複很多次。點「一輪迭代」看第二層。

第一層　整個專案
① 定邊界決策、預測時點 T0、可用資訊、驗證方式、停止條件你核准 brief.md
② 每輪審查說「round-review」；留哪些結論、下一輪／停止／提交你決定
③ 交付holdout 只評估一次、寫給決策者的報告你執行
② 決定「下一輪」時，回到一輪迭代
第二層　一輪迭代裡面做什麼（點任一步看細節）

選一步，這裡會顯示：做什麼、誰負責、用哪個 skill。

操作流程

拿到一道題目，就從第 0 站走到第 6 站

整個專案只有這一條路。每一站分兩部分：上面是你要做的事（含對 AI 說的話），下面是 AI 怎麼做的細節，想深入再展開。紅色菱形是人類閘門：走到這裡，AI 必須停下來等你決定。

一輪迭代：第 2–5 站每輪重複

在第 6 站決定「下一輪」時，回到第 2 站再跑一輪；決定「提交」才往下交付。
