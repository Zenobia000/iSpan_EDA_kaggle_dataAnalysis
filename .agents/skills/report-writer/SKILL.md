# Report Writer

讀者是**決策者**，不是資料科學家。輸出 `reports/report.md`。

```markdown
# <一句話結論：決策者不讀後文也能決定>

## 1. 決策建議（≤ 3 點，對應 `knowledge/findings.md` 的「需要你決定」）
## 2. 能做什麼（業務語言：每 1000 筆中…，是隨機的幾倍）
## 3. 證據（只放 robust 的增益；每個數字附 run_id）
## 4. 我們排除了什麼（無效的特徵、被推翻的假設、擋下的洩漏）
## 5. 限制與風險（預測 ≠ 因果；分布偏移；不可約誤差）
## 6. 下一步
```

驗收：每個數字都能對到 `experiments/log.jsonl` 的 run_id；沒有演算法術語也讀得懂。
