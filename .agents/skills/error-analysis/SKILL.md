# Error Analysis

1. 取 OOF 預測（每列在它是驗證集時的預測）
2. 切片：依類別欄位、數值分箱、時間；**事後分析可以用預測時點之後的欄位**（這是解釋，不是特徵）
3. 看最嚴重的誤報 / 漏報各 20 筆，找共同點
4. 每個發現寫成：錯誤 → 可能原因 → **可約**（缺特徵 → 下一輪要驗證的假設）或**不可約**（預測當下資訊根本不存在 → 沉澱候選）

不可約誤差是商業結論，不是模型失敗：寫進 `knowledge/findings.md`「給決策者」的「模型做不到」，並思考是否需要另一個預測時點。
