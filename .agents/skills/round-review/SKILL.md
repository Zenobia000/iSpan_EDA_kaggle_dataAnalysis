# Round Review

**你整理證據並給建議；決定由人類做。**

## 1. 這一輪的摘要（讀 `knowledge/log.md` 與 `experiments/log.jsonl`）
| 項目 | 內容 |
|---|---|
| 這輪試了什麼 | 逐項，一句話 |
| 穩健的進步 | 哪些、多少、每個 fold 都進步嗎（附 run_id） |
| 沒用 / 被推翻 | 哪些、為什麼 |
| 洩漏檢查 | 新特徵有沒有通過擾動測試 |
| 目前最佳 vs 基準 | 主指標，對兩種基準各好多少 |
| 卡住的地方 | |

## 2. 對照停止條件（`knowledge/brief.md` §5）
| 條件 | 門檻 | 目前 | 達成？ |
|---|---|---|---|

## 3. 沉澱候選（knowledge-capture 第 2 節）
列出 3–5 條候選，問：「這幾條要留在 findings.md 嗎？」

## 4. 建議（只給一個，並說理由）
下一輪（要驗證的 1–3 件事）/ 停止 / 提交

## 5. 請人類決定
問：「留哪幾條？下一輪、停止，還是提交？」
得到答案後：更新 `knowledge/findings.md`，並在 `log.md` 追加一段「R<n> 結束：決定 ___」。
