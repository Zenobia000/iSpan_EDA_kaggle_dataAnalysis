# Round Review（人類閘門 ③）

**你整理證據並給建議；決定由人類做。** 不要替人類宣布「完成」。

## 1. 整理（全部附 run_id 或檔案路徑）
| 項目 | 內容 |
|---|---|
| 本輪輪次 | R? |
| 只改了什麼（逐項） | |
| robust 增益 | 哪些、多少、幾個 fold 進步 |
| 沒有增益 / 被推翻 | 哪些、原因 |
| 洩漏審查 | 新增的特徵群組是否都通過擾動測試；validation-agent 的判定 |
| 目前最佳 | 設定、主指標 mean ± std、對基準的提升 |

|---|---|---|---|

## 3. 建議（只給一個，並說理由）
- **下一輪**：要驗證的 1–3 個假設（H-xxx）與預期
- **停止**：邊際效益低於門檻 / 已達截止日
- **提交**：達到門檻；先確認 holdout 只會評估這一次

## 4. 請人類決定，然後沉澱
問：「下一輪 / 停止 / 提交？」得到答案後依 knowledge-capture：
- 更新 `knowledge/00_Home.md` 的 Now / Next
- 寫 Finding（含對營運的意義）；必要時更新 Decision Card 的「能做 / 不能做」
- 清空 `knowledge/00_Inbox/`
