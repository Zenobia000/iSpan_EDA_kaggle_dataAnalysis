| 切分方式 | 時間切分 / 群組 K-fold / K-fold / 時間序列回測（依「上線時要預測的是什麼」決定） |

| 主指標 | |
| 基準模型 | 不學習的基準（猜比例 / 平均 / 上週同一天），以及簡單模型基準（只用原始欄位） |
