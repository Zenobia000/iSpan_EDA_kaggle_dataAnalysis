# 研究日誌

> **AI 每次回報分析或實驗結果時，在最下方追加一段。** 失敗、卡住、方向錯了也要寫。
> 舊的段落不改寫；寫錯了就在下面追加更正。

格式：

```
## R<輪次>-<序號> · <日期> · <這次想回答的問題>
- 做了什麼：（一句話 + 程式位置，例如 notebooks/R1-xxx.ipynb）
- 結果：（數字，附 run_id）
- 結論：支持 / 推翻 / 不確定 / 卡住
- 坑或困難：（沒有就寫「無」）
- 下一步：
```

- 結果：—
- 結論：—
