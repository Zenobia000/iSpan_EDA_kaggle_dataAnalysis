# Prediction is not causation

## 一句話
模型能找出高風險個體，不代表介入能改變結果；介入的效果要用實驗量。

## 檢查清單
- [ ] 這個相關有沒有競爭解釋（混雜因素）？
- [ ] 分層後關聯還在嗎？
- [ ] 業務建議是否隱含了因果主張？若有 → 設計 A/B test
