# tests/

`src/` 的每個模組都要有測試。下面這一種**一定要有**：

## 洩漏擾動測試（test_leakage_*.py）

原理：竄改「預測當下還不知道」的資訊，然後重算特徵。合法特徵在預測時點之前的列上，值必須**完全不變**。

| 驗證方法 | 竄改什麼 | 檢查哪些列 |
|---|---|---|
| 時間切分 / backtest | cutoff 之後才「被觀察到」的事件：值打亂，時間往**更晚**移，事件仍留在未來 | 預測時點 < cutoff 的列 |
| K-fold / 群組 K-fold | target 與「答案的來源欄位」 | 全部列（特徵不得依賴答案；target encoding 要放進 Pipeline） |

要點：
- 「何時被觀察到」依 `knowledge/10_Brief/Validation Protocol.md` 的「資訊可得性」表決定，不是依發生時間
- 只能把未來事件往**更晚**移；往前移會讓合法的歷史特徵被誤判
- 測試要用**合成的小資料**，不依賴下載，任何機器都能跑
- 寫一個**故意洩漏**的反例群組，確認測試真的抓得到

這些測試由 hook（Claude）與 pre-commit（Codex 與手動操作）自動執行。
